# FCFS Non-Preemptive Scheduler

A web-based visualizer for **First Come, First Served (FCFS)** CPU scheduling. Add processes with arrival and burst times to view their execution order, Gantt chart, turnaround times, and waiting times.

## Run locally

1. Open a terminal in the project folder.
2. Install dependencies:

   ```sh
   npm install
   ```

3. Start the development server:

   ```sh
   npm run dev
   ```

4. Open the local URL printed in the terminal (usually `http://localhost:5173`).
